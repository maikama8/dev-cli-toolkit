# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-14

### Added

- `zt init` scaffolds a `node-api`, `react-app`, or `python-api` project.
- `zt env check` compares an env file with its example.
- `zt git commit`, `zt git cleanup`, and `zt git changelog`.
- `zt port who` and `zt port kill` for TCP listeners on Linux, macOS, and Windows.
- `zt http`, `zt json`, `zt base64`, `zt jwt decode`, `zt uuid`, and `zt doctor`.
- Plugin loading from `~/.ztrc`, plus `--json` output and color control.
